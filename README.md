A sleek and minimal React-based landing page serving as a temporary personal site and contact portal while the full portfolio is in development.

## 📖 About

**HelloWorld Lorenzo** is a branded landing page crafted for recruiters, collaborators, and tech enthusiasts to:

- View a personal message animated with a React Typewriter effect
- Access my **LinkedIn** and **GitHub** via interactive icons
- Easily send me a message via an **email form**, powered by EmailJS

This is a lightweight, responsive placeholder until my full developer portfolio launches.

---

## 🧰 Tech Stack

- **React** (with Vite)
- **TypeScript**
- **React Icons**
- **EmailJS** (client-side email service)
- **Custom CSS** for animations, layout, and theming

---

## 🔧 Features

- 🎨 Artsy, creative, modern branding — **HelloWorld Lorenzo**
- ⌨️ Dynamic animated message with [react-typewriter-animate](https://www.npmjs.com/package/react-typewriter-animate)
- 📬 Email form with validation and smooth UX
- 💻 Animated logo watermark that responds to mouse movement
- ⚡ Fast load time via Vite
